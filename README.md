
1. Clona o descarga el repositorio en tu máquina ejecutando este comando:

```
git clone https://github.com/Doral-Ciberseguridad/Demo-Windows-InfoStealer-Educativo-Python.git
```

2. Instala las dependencias necesarias (como rclone-python) ejecutando en tu terminal:

```
pip install rclone-python
```


3. Lanza el script de Python ejecutando en tu terminal:

```
python Windows_InfoStealer.py
```
