# Windows-InfoStealer-Python
He creado este archivo python para simular un InfoStealer y entender su comportamiento. 
Se ejecuta en la máquina target y recopila copia y exporta a la nube los directorios más importantes de Windows de manera automatizada. 
(Es importante tener instalado y configurado rclone previamente)
Este repositorio ha sido creado con fines éticos y demostrativos. Se debe de usar con ética y responsabilidad.
